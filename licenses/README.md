# Bundled component licenses

Generated by `wasm/build-steps/collect-licenses.sh` from the pinned source
trees on 2026-07-28, against the dependency pins recorded in `NOTICE`
Section 1. Do not edit by hand — see "Regenerating" below.

This directory reproduces the license text of every third-party project
statically linked into `wasm/dist/openslide.wasm`, as required by their
respective terms for binary redistribution (see `NOTICE` Section 1 for
the full list of components, upstream sources, and version pins).

## Regenerating

This directory is generated by `wasm/build-steps/collect-licenses.sh`
from the exact pinned source trees fetched by `wasm/dependencies/`. It
must be regenerated (and the result committed) whenever:

- a dependency pin in `wasm/dependencies/fetch-*.sh` changes, or
- a dependency's upstream project moves/renames its license file(s).

To regenerate, run the WASM Docker build (`npm run build:wasm`) and
copy the resulting `/build/out/licenses` directory from the build
container over this one, e.g.:

```sh
docker build -t openslide-wasm-builder ./wasm
docker create --name license-extract openslide-wasm-builder
docker cp license-extract:/build/out/licenses ./licenses
docker rm license-extract
```

`collect-licenses.sh` exits non-zero (failing the build) if any
component's license file cannot be found at any of its known
candidate paths, so a stale or incomplete `licenses/` tree will be
caught before publishing.

## Elections for dual/multi-licensed components

Where a bundled component offers a choice of license, openslide-js
elects one and ships only that option's text (see `NOTICE` Section 1
for the reasoning):

- Cairo — LGPL-2.1-only (`cairo/COPYING-LGPL-2.1`, not `COPYING-MPL-1.1`)
- FreeType — FTL (`freetype/FTL.TXT`, not `docs/GPLv2.TXT`)
- zstd — BSD-3-Clause (`zstd/LICENSE`, not `COPYING`, which is GPL-2.0)

## SQLite

The SQLite amalgamation carries no copyright notice; it is dedicated
to the public domain via the "blessing" comment reproduced in
`sqlite/BLESSING.txt`. The build fetches SQLite from a fork
(`https://github.com/frida/sqlite`, used for its Meson build files)
rather than from `sqlite.org` directly — see `sqlite/BLESSING.txt` for
details and `NOTICE` Section 1 for the corrected upstream URL.
